# triage-geometry

A dual-layer approach to reducing dangerous undertriage errors in LLM-based clinical triage. This project investigates whether structured prompting strategies and hidden-state geometric analysis can detect and reduce undertriage failures in Llama 3 8B without any clinical fine-tuning.

## Overview

Consumer health AI is deploying at scale, but open-source LLMs ship without clinical safety tuning. This project evaluates two complementary safety layers:

1. **Behavioral (prompting):** Four prompting conditions: zero-shot baseline, system-level safety instructions, few-shot with ESI exemplars, and chain-of-thought severity reasoning. Evaluated against gold-standard ESI labels on exact match, undertriage, and overtriage rates.

2. **Representational (geometry):** Hidden-state activations extracted from the last four transformer layers are analyzed using PCA, t-SNE, silhouette scoring, and logistic regression probes to test whether undertriage errors occupy a geometrically distinct region of the model's representation space.

The integration analysis tests whether a dual-layer system with geometric flagging on top of the best prompting strategy achieves a lower undertriage rate than either layer alone.

## Dataset

150 clinical vignettes adapted from the ESI Handbook v4 (Chapters 9 and 10), with gold-standard ESI labels 1–5. Distribution:

| ESI Level | Count | Description                                |
| --------- | ----- | ------------------------------------------ |
| 1         | 23    | Immediate lifesaving intervention required |
| 2         | 42    | High-risk, should not wait                 |
| 3         | 41    | Two or more resources expected             |
| 4         | 20    | One resource expected                      |
| 5         | 24    | No resources expected                      |

## Key Results

**Behavioral (prompting):**

| Condition        | Correct | Undertriage | Overtriage |
| ---------------- | ------- | ----------- | ---------- |
| zero_shot        | 44.0%   | 24.0%       | 32.0%      |
| system_safety    | 36.7%   | 16.0%       | 47.3%      |
| few_shot         | 56.7%   | 12.7%       | 30.7%      |
| chain_of_thought | 27.3%   | 52.0%       | 16.0%      |

**Geometric (representation):**

- PCA and t-SNE show four cleanly separated clusters by prompting condition.
- Within-condition probe AUC: 0.83 for zero_shot and system_safety, ~0.65 for few-shot and CoT. Detectable geometric signature within conditions.

**Dual-layer integration:**

- zero_shot alone: 24.0% undertriage
- few_shot alone: 12.7% undertriage
- Dual-layer: 13.3% undertriage on threshold of 0.3 (escalating 23% of cases to few_shot)
